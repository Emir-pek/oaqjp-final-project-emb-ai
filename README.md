# Final Project: Emotion Detection

## Project Overview
This repository contains the Final Project for the AI course. The project is an Emotion Detection application built using Python, the Flask web framework, and the Watson NLP library.

## Project Details
- **Project Name:** Final Project - Emotion Detection App
- **Objective:** To build and deploy a web-based application that analyzes user-provided text and detects emotions such as anger, disgust, fear, joy, and sadness, along with identifying the dominant emotion.

## Features
- **Emotion Analysis:** Utilizes Watson NLP library to return emotion scores and the dominant emotion.
- **Web Interface:** Deployed as a web application using Flask.
- **Error Handling:** Manages invalid or blank inputs gracefully (e.g., returning proper messages for HTTP 400 status codes).
- **Unit Testing:** Includes comprehensive unit tests using Python's `unittest` module.
- **Code Quality:** Formatted and checked with `pylint` to ensure PEP8 compliance.
